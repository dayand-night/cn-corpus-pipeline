# 中文语料清洗与质量分析 Pipeline

对公开中文正文做端到端清洗与质量治理，产出可直接用于训练或检索的结构化数据集，
并输出可追溯的分阶段质量报告。

## 处理流程

    raw (RSS / 本地文件)
      -> 去缺失（正文为空的记录分类统计，不填充）
      -> 规范化（NFKC、去 HTML 标签、去代码块、统一空白）
      -> 模板噪声剔除（短行 + 导航词规则）
      -> 精确去重（SHA256）
      -> 近似去重（SimHash 64bit + 分带 LSH，汉明距离 <= 3）
      -> 质量打分（长度 / 中文占比 / 重复行 / 符号占比 / 字符多样性）
      -> clean.jsonl + report.md

## 为什么这么设计

- **近似去重用分带 LSH 而不是两两比较**：两两比较是 O(n^2)，
  三千条还能跑，五万条就跑不动。按 16 位分带建桶，只在桶内比汉明距离。
- **缺失正文不填充**：正文缺失没有可靠的统计量可补，强行填充会污染下游，
  所以剔除并单独计数，让缺失率成为可观测指标。
- **质量规则可解释**：五条规则都是人能读懂、能复现的，不用模型打分，
  避免"黑盒过滤"导致数据不可追溯。

## 运行

    python corpus_clean.py --fetch     # 抓一轮公开 RSS 到 raw/
    python corpus_clean.py             # 跑完整流程
    python corpus_clean.py --max-dist 2  # 收紧近似去重阈值

零第三方依赖，只用标准库。
